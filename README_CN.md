# MarkXia

[English](README.md)

MarkXia 是一个 Figma 与 FigJam 小组件，可直接在画布上编写、编辑并渲染 Markdown 笔记。

该小组件使用 Figma 同步状态保存笔记内容，并通过轻量编辑面板进行更新。

它支持通过小组件属性菜单切换浅色与深色主题。

## 功能

- 可在 Figma UI 面板中编辑 Markdown，并可选择应用后保持编辑器打开，或保存后关闭编辑器。

- 通过 `useSyncedState` 保存 Markdown、标题和主题，使小组件状态随 Figma 文件一起保存。

- 运行时不访问外部网络；`manifest.json` 将允许域名设置为 `none`。

## 支持的 Markdown 语法

MarkXia 支持在 Figma 画布上原生渲染标准 Markdown 和 GitHub 风格 Markdown (GFM) 的子集：

| Markdown 语法特性 | 语法示例 | 支持状态 | 备注 / 局限性 |
| :--- | :--- | :---: | :--- |
| **H1, H2, H3 标题** | `# 标题 1`<br>`## 标题 2`<br>`### 标题 3` | ✅ | 主标题渲染为大号加粗字体。 |
| **H4, H5, H6 标题** | `#### 标题 4` | ❌ | 会被当作普通段落文本渲染。 |
| **粗体文本** | `**粗体**` 或 `__粗体__` | ✅ | 渲染为加粗字体。 |
| **斜体文本** | `*斜体*` 或 `_斜体_` | ✅ | 渲染为斜体字体。 |
| **粗斜体文本** | `***粗斜体***` | ❌ | 无法正确同时解析两种样式。 |
| **删除线** | `~~删除线~~` | ❌ | 会直接渲染出 `~~` 符号。 |
| **下划线** | `<u>下划线</u>` | ❌ | 会直接渲染出 HTML 标签本身。 |
| **标记/高亮** | `==高亮==` | ❌ | 会直接渲染出 `==` 符号。 |
| **上标与下标** | `x^2^`, `H~2~O` | ❌ | 会直接渲染出 `^` 或 `~` 符号。 |
| **普通段落** | 普通文本 | ✅ | 使用主题对应的文本颜色进行常规排版。 |
| **强制换行** | 行尾空格 或 `<br>` | ❌ | 直接渲染为单行或 HTML 标签。段落之间需使用双回车进行分段。 |
| **无序列表** | `- 列表项` 或 `* 列表项` | ✅ | 渲染为带有自定义项目符号 `•` 的列表。 |
| **有序列表** | `1. 列表项` | ✅ | 渲染为带自动递增序号的列表。 |
| **嵌套列表** | 缩进列表项 | ❌ | 行首空格会被 `trim()` 移除，所有列表项均呈扁平化渲染。 |
| **任务列表** | `- [ ] 待办` | ❌ | 会直接渲染为 `• [ ] 待办` 纯文本。 |
| **自定义列表** | `名词`<br>`: 定义` | ❌ | 会被当作普通段落文本渲染。 |
| **标准引用块** | `> 引用内容` | ✅ | 渲染为带有主题色左边框和斜体文字的引用样式。 |
| **嵌套引用** | `> > 嵌套` | ❌ | 扁平化解析，会渲染为带有多余 `>` 字符的单级引用。 |
| **GFM 警告框** | `> [!NOTE]` | ❌ | 会渲染为包含 `[!NOTE]` 文本的普通引用块。 |
| **行内代码** | `` `代码` `` | ✅ | 渲染为带有主题强调色和间距背景的行内代码。 |
| **围栏代码块** | ` ```javascript ` | ✅ | 渲染在带背景色的代码块容器中。 |
| **语法高亮** | ` ```python ` | ❌ | 代码块中的代码将呈单一纯文本显示，无语法着色。 |
| **超链接** | `[文字](链接)` | ❌ | 会直接渲染为 `[文字](链接)` 纯文本。 |
| **图片展示** | `![图片](链接)` | ❌ | 会直接渲染为 `![图片](链接)` 纯文本。 |
| **简单表格** | `| 表头 |` | ✅ | 基于 AutoLayout 自动布局，在 Figma 画布上渲染原生表格。 |
| **表格对齐** | `| :--- | ---: |` | ❌ | 忽略对齐标记，所有单元格文本默认靠左对齐。 |
| **LaTeX 数学公式** | `$E=mc^2$` 或 `$$...$$` | ❌ | 直接渲染为 LaTeX 原始公式代码。 |
| **脚注** | `[^1]` | ❌ | 直接渲染为 `[^1]` 纯文本。 |
| **详情折叠框** | `<details>` | ❌ | 会直接渲染出原始 HTML 标签。 |
| **键盘按键标签** | `<kbd>Ctrl</kbd>` | ❌ | 会直接渲染出原始 HTML 标签。 |
| **表情符号** | `:rocket:` | ❌ | 无法解析短代码，但支持直接在文本中输入 Unicode 表情符号（如 `🚀`）。 |
| **Mermaid 流程图** | ` ```mermaid ` | ❌ | 会被当作普通代码块，直接显示 Mermaid 原始代码文本。 |
